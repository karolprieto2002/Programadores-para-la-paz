El login es el proceso mediante el cual un usuario ingresa a una aplicación utilizando sus credenciales para identificarse. Esto permite verificar quién está accediendo al sistema antes de usar determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. De esta manera se evita que personas no autorizadas modifiquen o consulten datos sensibles. No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni información privada de la comunidad.
