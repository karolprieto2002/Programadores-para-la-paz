Backlog priorizado

1. Como ciudadano quiero registrar una incidencia para dejar evidencia del caso.

2. Como coordinador quiero recibir una notificación en Telegram cuando se registre un nuevo reporte para hacer seguimiento oportuno.

3. Como miembro del equipo quiero consultar los reportes registrados para verificar su estado.

4. Como administrador quiero actualizar el estado de un reporte para mantener informada a la comunidad.

5. Como ciudadano quiero conocer el estado de mi reporte para saber si ya fue revisado.
